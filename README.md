# Personal Library Manager API

A RESTful API for managing personal book collections with advanced search, filtering, and status tracking functionality.

---

## 🚀 Overview
The Personal Library Manager API allows users to organize, track, and manage their book collections efficiently. The system is designed with clean architecture principles and optimized database interactions to ensure scalability and ease of integration.

---

## ✨ Key Features
- Full CRUD operations for books
- Search books by title or author
- Filter books by read/unread status
- Update book details and reading progress
- Clean and intuitive RESTful endpoints
- Centralized error handling and validation

---

## 🛠️ Tech Stack
- **Backend:** Node.js, Express.js  
- **Database:** MongoDB, Mongoose ODM  
- **Architecture:** RESTful API  
- **Tools:** Git, GitHub, Postman  

---

## 📂 API Capabilities
- Add and manage books
- Retrieve books with search and filtering options
- Update book metadata and reading status
- Delete books securely

---

## ⚙️ Installation & Setup
```bash
git clone https://github.com/Ahmed-Samir12/Personal-Library-Manager.git
cd Personal-Library-Manager
npm install
npm run dev
```
